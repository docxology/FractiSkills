# Archived live evidence

The published [version record](https://doi.org/10.5281/zenodo.22712651)
preserves the live survey as a 49-page PDF. The file's MD5 in the Zenodo
record is `14be55691373e95f8dd94d70520e52b3`. The archive contains the PDF.
The original raw inventory, per-run manifests, and augmentation receipts are
not provided as downloadable assets with that version.

The release reports 405 discovered pages, 405 published skills, 497896 skill
words, 173 augmentation attempts with 169 successes, and an 88.9% sitemap-only
miss rate. The archival augmentation table includes HTTP 400 and HTTP 404
failures. The [claim ledger](../data/claim_ledger.yaml) retains the historical
values, their observation date, and the original run artifact and field names.
Fixture counts and figures are generated separately and carry a fixture
evidence-origin marker.
