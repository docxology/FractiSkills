# Abstract {#sec:abstract}

FractiSkills turns an entire live website into a complete, organized library of portable agent skills. Over an observation window of {{OBSERVATION_WINDOW}}, the pipeline discovered **{{TOTAL_PAGES}} pages** of the *SS Vibelandia Omniversal Canvas* ({{BASE_URL}}) — an openly shared, art-project website that welcomes crawlers — through its declared sitemap ({{SITEMAP_URLS}} URLs) plus a bounded, robots-respecting breadth-first crawl ({{VIA_CRAWL_ONLY}} crawl-only additions, {{ALIAS_PAGES}} redirect aliases resolved). Each page was rendered, by the [Skillarum](@skillarum) engine, into one validated `SKILL.md` package with full source provenance: **{{SKILL_COUNT}} skills, {{TOTAL_WORDS}} words**, organized into **{{SECTION_COUNT}} sections** that mirror the site's own information architecture.

Several site pages are client-rendered shells whose real documents live behind same-origin JSON endpoints. FractiSkills extends Skillarum's deterministic generator with a declared augmentation boundary that retrieves those documents ({{AUGMENT_OK}} of {{AUGMENT_ATTEMPTS}} attempts, {{AUGMENT_CHARS}} document characters) and stamps each retrieval into the skill body and manifest. Five deterministic figures visualize the site's section structure, discovery provenance, skill-size distribution, cross-section link flow, and augmentation footprint. The result is a reproducible, evidence-gated publication: every numeric claim in this manuscript is a bound token hydrated from persisted run artifacts, and the entire pipeline reruns end-to-end from a clean checkout.
