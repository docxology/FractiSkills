# Abstract {#sec:abstract}

*FractiSkills* treats an entire website as a corpus of agent skills: every reachable page is normalized into a `SKILL.md`-style artifact so that a whole site — not a single document — becomes loadable context for an agent. The work is organized around a four-stage pipeline — discover, render, publish, research — with Skillarum [@skillarum] serving as the engine that turns raw crawl output into citable, receipt-bearing skill documents. Discovery unions the declared sitemap with a bounded, robots-respecting breadth-first crawl (reaching a maximum depth of {{TOP_DEPTH}}), resolves redirect and canonical aliases, and partitions every page into site-derived sections; the render stage emits one receipt-bearing skill per page; publish and research then validate, organize, and measure the corpus.

The resulting corpus covers {{TOTAL_PAGES}} pages from {{SITEMAP_URLS}} sitemap URLs, organized into {{SECTION_COUNT}} sections and {{SKILL_COUNT}} skills totaling {{TOTAL_WORDS}} words ({{TOTAL_CHARS}} characters). Augmentation — a declared, same-origin document retrieval for client-rendered pages — was attempted {{AUGMENT_ATTEMPTS}} times and succeeded {{AUGMENT_OK}} times ({{AUGMENT_CHARS}} document characters retrieved), with {{AUGMENT_FAILED}} failures recorded as receipts. The size effect is stark: augmented skills have a median of {{MEDIAN_WORDS_AUGMENTED}} words versus {{MEDIAN_WORDS_STATIC}} for static pages, a ratio of {{AUGMENT_RATIO}}$\times$. The run issued {{REQUEST_COUNT}} network requests, all evidence origins marked {{EVIDENCE_ORIGINS}}, under pipeline version {{PIPELINE_VERSION}} and cache version {{CACHE_VERSION}}.

Reproducibility is enforced rather than promised: every statistic in this manuscript is emitted as a token that must resolve against a machine-generated data contract, and every page carries a fetch receipt — URL, timestamp, SHA-256 content hash, and augmentation status — so any number can be traced to a specific observation within the {{OBSERVATION_WINDOW}} window. Failed augmentations are reported, not silently dropped. Keywords: agent skills, SKILL.md, web scraping, Skillarum, provenance, reproducible research.
